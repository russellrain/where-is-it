Where Is It

Privacy

Last updated October 31, 2026

Short version: Where Is It does not collect, store or send any personal information. There are no accounts, cookies, analytics, ads or trackers. Scores are never sent anywhere. The site is hosted on GitHub Pages, and GitHub logs visitors' IP addresses for security, as described below.

What the game collects

Nothing. The game runs entirely in the browser. It doesn't send answers, scores or anything else to me or to anyone else. I have no server and no database, so I couldn't see student data even if I wanted to.

No names or accounts

The game never asks students for their name or any other information about themselves. Nothing about a student is saved on the device between games.

Scores

When a student clicks Copy score, the score text (quiz title, score, time and missed countries) is copied to that device's clipboard. It goes only where the student pastes it, such as an assignment you set up in your own learning platform, which already knows who the student is.

Quiz links

Quiz settings (the country list, title, number of questions and so on) are stored in the link itself, not on a server. Anyone with a link can see those settings. Because the link is part of each page request, it may also appear in GitHub's logs. Please don't put student names or other personal details in a quiz title.

Hosting: GitHub Pages

This site is hosted on GitHub Pages. According to GitHub's documentation, when someone visits a GitHub Pages site, GitHub logs and stores the visitor's IP address for security purposes, whether or not the visitor is signed in to GitHub. Like any web server, GitHub also receives standard request information, such as the page requested and the browser type.

That logging is done by GitHub, not by me. I don't receive these logs or any visitor statistics from GitHub. GitHub's handling of this information is covered by the GitHub General Privacy Statement.

Third-party code and data

The map library (D3), map shapes, country data and flags are all bundled into this site and served from the same place as the game. While playing, the game does not load anything from other servers, so no other company receives information about students' visits.

The page footer links to russpuppy.com and Natural Earth. Those sites open only if someone clicks the link, and they have their own privacy policies.

Students and children

Where Is It is made for classroom use, including by children. Because it doesn't collect personal information from students, there is nothing for me to store, share, sell or delete.

Changes

If the game ever starts collecting data, this page will be updated first, and the date at the top will change. Every change to this page is also recorded in the project's public source code.

Questions

You can ask a question by opening an issue on GitHub or through russpuppy.com.
