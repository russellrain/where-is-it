Where Is It

About

Where Is It is a free map game. You get one place at a time and have to find it on the map. A timer runs, and at the end you see your score and which ones you missed.

Anyone can build their own quiz on the setup page by picking exactly what you want to practice, then share it with a link. That makes it handy for classrooms, too. There are no accounts or sign-ups. The game works in English, Spanish and French.

Where Is It is made by russpuppy. The source code is public on GitHub.

Privacy

Last updated October 31, 2026

Short version: Where Is It does not collect, store or send any personal information. There are no accounts, cookies, analytics, ads or trackers. Scores are never sent anywhere. The site is hosted on GitHub Pages, and GitHub logs visitors' IP addresses for security, as described below.

What the game collects

Nothing. The game runs entirely in the browser. It doesn't send answers, scores or anything else to me or to anyone else. I have no server and no database, so I couldn't see anyone's data even if I wanted to.

No names or accounts

The game never asks for your name or any other information about you. Nothing about you is saved on the device between games. The only things the site remembers are whether someone switched to light or dark mode and which language they picked. Both are saved in the browser so the choice sticks, and are never sent anywhere.

Scores

When you click Copy score, the score text (quiz title, score, time and what you missed) is copied to your device's clipboard. It goes only where you paste it.

Quiz links

Quiz settings (what's included, the title, number of questions and so on) are stored in the link itself, not on a server. Anyone with a link can see those settings. Because the link is part of each page request, it may also appear in GitHub's logs. Please don't put names or other personal details in a quiz title.

Hosting: GitHub Pages

This site is hosted on GitHub Pages. According to GitHub's documentation, when someone visits a GitHub Pages site, GitHub logs and stores the visitor's IP address for security purposes, whether or not the visitor is signed in to GitHub. Like any web server, GitHub also receives standard request information, such as the page requested and the browser type.

That logging is done by GitHub, not by me. I don't receive these logs or any visitor statistics from GitHub. GitHub's handling of this information is covered by the GitHub General Privacy Statement.

Third-party code and data

The map library (D3), QR code generator, map shapes, place data and flags are all bundled into this site and served from the same place as the game. While playing, the game does not load anything from other servers, so no other company receives information about your visit.

The setup page footer and this page link to other sites, such as russpuppy.com and Natural Earth. Those sites open only if someone clicks the link, and they have their own privacy policies.

Children

Where Is It can be played by people of any age, including children. Because it doesn't collect personal information from anyone, there is nothing to store, share, sell or delete.

Changes

If the game ever starts collecting data, this section will be updated first, and its date will change. Every change to this page is also recorded in the project's public source code.
